# Nourhan Tarek Ata — Portfolio

A responsive React portfolio built with Vite, Tailwind CSS, Framer Motion, and Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Deploy to Vercel

1. Push this project to a GitHub repository.
2. In Vercel, choose **Add New → Project** and import the repository.
3. Vercel should detect Vite automatically.
4. Use `npm run build` as the build command and `dist` as the output directory.
5. Click **Deploy**.

The included `vercel.json` supports client-side routing if routes are added later.

## Personalize before publishing

- Add project demo and GitHub URLs in `src/App.jsx` (`projects` array).
- Add a profile photo if desired.
- Verify all social links and contact details.
- Add a downloadable CV file under `public/` and update the CV link in the hero section.
